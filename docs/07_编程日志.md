# 编程日志

按时间倒序记录实现过程与踩坑，供后续维护参考。

## 2026-11-09 · v2.0.0 手机端独立化

### 目标

原 APK 是 WebView 壳，必须连电脑上的 FastAPI 才能用。v2.0 把采集、存储、计算、预测全部搬进手机，
后端降级为研究工具。

### 关键决策

| 决策 | 取舍 |
|------|------|
| 前端仍用原生 JS + Canvas | 无构建链，改完直接进 assets，APK 只 2.3 MB |
| 不用本地 HTTP 服务（NanoHTTPD） | 直接走 `@JavascriptInterface` 桥，少一个端口与生命周期问题 |
| 不做在线岭回归 | 手机上训练 11 维岭回归收益极低，只移植信号库 + 走前验证 |
| 指标/预测口径与 Python 版对齐 | 便于对照两边结论，出问题能定位是谁错 |

### 踩坑记录

1. **新版 cmdline-tools 的 `sdkmanager` 会崩**
   报 `AccessDeniedException: /opt/android-sdk/.sdk/lock`。原因是它已被标记 deprecated，
   改由 `android sdk --sdk=<path> install ...` 接管；同时 `/opt/android-sdk` 之前被 root 写过，
   要先 `chown -R $USER`，否则锁文件永远拿不到。

2. **Gradle 8.2.1 不支持 JDK 21**
   Debian 13 仓库没有 openjdk-17，只能升 Gradle 到 8.9（JDK 21 从这里开始正式支持）。
   `android/build-apk.sh` 已同步改成 8.9 + 自适应版本号产物名。

3. **`JSONArray.put` 会抛受检异常**
   `Engine.sparkline()` 里两处 `put` 没包 try/catch，javac 直接报
   `unreported exception JSONException`。整个方法体包一层 try 即可，不要逐行加。

4. **`ScheduledExecutorService` 不能复用**
   改刷新间隔时若只 `shutdownNow()` 再 `schedule()`，会抛 `RejectedExecutionException`。
   必须整体替换实例：新建 → 旧实例 shutdown → 重新排程。

5. **CSS Grid 的 `1fr` 会被内容撑破**
   `repeat(3, 1fr)` 在窄屏上会被 min-content 撑开，导致整页横向溢出、底部第 4 个 tab 看不见。
   全部改成 `repeat(n, minmax(0, 1fr))`，并给数值单元加 `text-overflow: ellipsis`。

6. **headless Chrome 截图不可信**
   Windows 显示缩放 125% 时，`--window-size=390,844` 截出来的是 487 CSS px 的页面左半边，
   看起来像"右侧被裁"，实际是截图工具问题。验证移动端布局要用「固定宽 iframe + 按比例放大窗口」，
   或直接用 DevTools 协议设 `deviceMetrics`。

7. **Gitee 私有仓库的 Release 需要令牌**
   `/releases/latest` 与 APK 下载地址都必须带 `access_token`。客户端把令牌存
   AndroidKeyStore 加密后的 SharedPreferences，不落明文、不上传服务器。
